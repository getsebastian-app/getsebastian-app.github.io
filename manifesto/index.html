A note on safety

AI agents are powerful — and that power comes with real responsibility.

OpenClaw can read files, run commands, send messages, and access APIs you connect. That's what makes it useful. It's also why you should be thoughtful about what you give it access to.

Start small. Connect one messenger, one tool. See how it works before expanding.

Don't hand over the keys to everything. Give access only to what you actually need automated. Your main email, banking, and admin panels can wait.

Review what it does. Read the logs. Check the actions. Trust builds over time, not on day one.

This is early territory. AI agents are a new category. The industry — us included — is still learning the boundaries. We build guardrails, but no system is bulletproof.

We'd rather be honest about this than pretend it's all figured out. The upside is real. So is the need for caution.
